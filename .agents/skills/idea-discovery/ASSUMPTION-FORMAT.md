# assumption-xxxx.md

## Job of this doc

A THING TAKEN AS TRUE WITHOUT PROOF + what breaks if it is wrong. Makes a hidden
belief explicit so it can be tracked and, if shaky, validated. Answers "what are
we betting on?" - not a requirement, not a decision. An assumption with no
"impact if wrong" is not worth recording.

## Assumption

The belief, stated as a plain claim.

## Description

What it means and where it came from.

## Evidence

What weakly supports it today (and how weak that is).

## Impact if Wrong

What breaks downstream if the claim is false. This is the reason to record it.

## Constraints Derived

What the rest of the work must do BECAUSE this is assumed true.

## Validation Needed

If shaky, link the validation doc that should prove or kill it.
