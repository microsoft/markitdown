# MarkItDown Studio

A Windows desktop application for converting files into Markdown using Microsoft MarkItDown.

## Run

```bash
python app.py
```

## Features

- Modern desktop UI with navigation pages for Home, Single File, Batch, Watcher, History, Obsidian, AI Tools, OCR, Settings, and About
- SQLite-backed history and settings
- Background file watching for automatic conversion
- Placeholder integrations for Obsidian, AI tools, and OCR
- Backend conversion through the local MarkItDown package
